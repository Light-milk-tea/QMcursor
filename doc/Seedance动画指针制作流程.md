# Seedance 动画指针制作流程（现行）

2026-08 伊蕾娜普通选择第二版已验证：动作效果以本流程为准。  
**之后新主题的角色态动画都按本文做**，不再用 Prompt B、逐像素拆层或 `build_assets.py` 猜层派生续帧。

静帧审美仍走高清像素风 concept（GenerateImage）。动态交给 Seedance 图生视频，再抽帧封装成 Windows 原生 ANI。关 QMcursor 后仍由系统播放。不做物理摇摆、不做挂坠。

配套：

- 封装与校验：[`ANI动态鼠标指针制作标准流程.md`](ANI动态鼠标指针制作标准流程.md)
- 线框静帧：[`线框风格像素指针生成提示词.md`](线框风格像素指针生成提示词.md)

---

## 1. 总流程

```text
S0  确认高清 concept 静帧（用户拍板）
 → S1  Seedance 图生视频（分层闲置，禁止整身钟摆）
 → S2  均匀抽 16 帧
 → S3  边缘洪水抠棋盘 / 浅底 → 左上对齐 → 整只角色装进 128×128
 → S4  绿色底 GIF（约 100ms/帧）给用户看
 → S5  用户确认后打 32 位 ANI（JifRate=6）并导入 / 应用
```

未确认静帧，禁止进 Seedance。未确认 GIF，禁止打正式 ANI、禁止替换系统指针。

标杆成片：`视频生成_副本/伊蕾娜-seedance2.0-v2.mp4`（提示词见该目录 `生成prompt.md`）。

---

## 2. S0 静帧

- 用已确认的 `concept/01-normal-select-concept.png`（或同构图导出图）当**唯一首帧**。
- 构图锁死：左侧 / 左上热点器物 + 中央偏右 Q 版角色。
- 眼睛、描边、配色按该主题 `style-summary.md`。
- 不要用真 48 量化稿、不要用手拼小人当首帧。

其它角色态同样：先有一张确认过的 concept，再各自生成一段视频。功能态（文本、准星、缩放、移动）默认静帧复用，不必进 Seedance。

---

## 3. S1 Seedance

入口：即梦 / 豆包等已上线 Seedance 2.0 或 2.5 的图生视频。

| 项 | 锁定 |
|---|---|
| 模式 | 图生视频，上传 S0 静帧 |
| 比例 | **1:1**（不要 16:9） |
| 时长 | **最短档，约 4 秒**。不要 15/30 秒，不要延长 |
| 运动 | 慢 |
| 镜头 | 锁定，禁止运镜 |
| 次数 | 同一词连跑 4–6 条，只留尖端稳、分层能动的 |

### 3.1 提示词结构（每套主题改方括号）

不要写「摆到一侧再摆回来」。那句会生成整个人左右摇的钟摆，第一版伊蕾娜就是这样失败的。

```text
严格以上传图片为唯一首帧。不要重绘角色，不要换构图、比例、裁切和画风。固定机位，不推拉、不摇移、不旋转、不缩放。棋盘格或纯色背景保持原样，不要出现地面、房间或新道具。

这是鼠标指针的短循环闲置，不是角色表演镜头。

绝对锁死、全程不位移：
- [左侧热点器物的柄和最上方尖端]
- 角色双脚、身体中轴、头部中心
- 握器物的手
- 脸部位置；[眼型锁死，例如闭眼横线，不要睁眼]
- 近黑硬描边、像素块面、配色与首帧一致

不要做「整个人左右摇」的不倒翁/钟摆动作。身体不要平移，不要像挂件一样晃。

要做分层闲置，几个部件错开动，不要同步摇摆：

1. 主动作：[例如帽尖点头，根部几乎不动；饰带晚半拍]
2. 次动作：[例如发梢 / 马尾跟随，比主动作晚一点]
3. 辅助：[例如衣摆起伏；器物末梢轻颤，器物柄完全不动]
4. 点缀：[例如胸针只闪一次亮度，位置不变]

呼吸：胸腔和肩膀有几乎看不出的起伏，但脚和热点尖端钉在原地。

时间线（约 4 秒，首尾要能接上）：
- 0.0s 与上传图完全相同
- 0.5s 主动作开始，次动作还没动
- 1.5s 主动作到极值，次动作和辅助才跟上
- 2.5s 主动作回弹，点缀闪一下
- 3.5s 次动作跟随回落
- 4.0s 全部回到与首帧几乎相同的位置，方便循环

禁止：整个人左右横移、旋转、走近走远、热点尖端移动、换脸、开眼、运动模糊、残影、溶解、闪白、粒子风暴、魔法阵、文字水印。

保持硬边像素插画，干净色块，不要写成实或油画。
```

模型还是只会左右摇时，在词末追加：

```text
再次强调：禁止角色整体左右摇摆。如果只能做一个动作，就只做[主动作]和[次动作]，身体完全静止。宁可动作少，也不要钟摆。
```

### 3.2 伊蕾娜已验证词

帽尖点头、发梢跟随、袍摆、扫帚苗轻颤、胸前金星闪一次。全文见 `视频生成_副本/生成prompt.md`。

### 3.3 弃片标准

整个人横着摇、尖端乱飘、换脸、推镜、首尾对不上，直接丢掉，不要靠后期硬修。

---

## 4. S2 抽帧

从采用的视频均匀抽 **16 帧**（约 4 秒 / 24fps 片源即可均分）。

- 指针预览与 ANI 默认 **约 100ms/帧**（`JifRate=6`），16 帧循环约 1.6 秒。
- 不要只抽 8 帧交差；8 帧是旧像素派生约定，本流程已改。
- 导出尽量 1:1、无水印。若平台给出 4:3，抽帧后仍按主体裁，不要留大块棋盘。

---

## 5. S3 处理成正式帧

视频里的棋盘格是画进去的，必须抠掉。银白发、白领、浅色器物尖接近棋盘，**只能清与画面边缘连通的浅灰/近白**，禁止全局把浅色当成背景删。

对齐不要用「全图最高的那一像素」。软塌帽尖、呆毛往往在右上，用它当锚会把身子推出画布。

正确锚点：**角色左上侧**（热点器物或左上轮廓），以首帧该点为基准平移其余帧。然后：

1. 取 16 帧并集包围盒，留 6px 边。
2. LANCZOS 整只角色装进 **128×128**，四周留边。
3. Alpha 收到 0 或 255。
4. 热点写入左上锚点，16 帧同一坐标。

参考实现：`视频生成_副本/make_trial_cursor.py`（抠底、左上对齐、128 画布、打 ANI、应用普通选择）。

禁止：

- 把量化真 48 格当正式帧
- 用生图模型逐帧重画续帧
- 对齐到软塌帽尖 / 最高像素导致角色被裁没

---

## 6. S4 预览（强制）

每一轮处理完都要直接展示 GIF，不能只给路径或文字。

- 用本轮 128 正式帧
- 浅绿底（如 `#B6D2B8`）暴露透明洞
- 最近邻放大预览
- 约 100ms/帧循环

用户确认前不要构建 ANI，不要同步主题，不要替换系统指针。

---

## 7. S5 封装与应用

| 项 | 现行值 |
|---|---|
| 画布 | 128×128 |
| 帧数 | 16 |
| 位深 | **32 位 RGBA**（高清缩小后色多，不要 8 位索引） |
| 帧间隔 | `JifRate=6` |
| 容器 | RIFF `ACON`，每帧带相同热点的 CUR |

普通选择文件名：`Normal.ani`。导入 QMcursor 时也可识别 `arrow.ani`。

试做阶段可以只替换普通选择，其它角色沿用当前方案。完整主题再按角色表补：`Help` / `Working` / `Unavailable` / `Link` 等角色态各自走 S0–S5；功能态用确认过的静帧打单帧或 16 帧相同的 ANI。

构建可复用 `.cursor/skills/generate-qmcursor-theme/scripts/build_ani_theme.py`。本流程正式帧已是 128 透明 PNG 时，不要再对主体做最近邻缩放。

## 8. 角色优先级

| 优先级 | 角色 | 做法 |
|---|---|---|
| 先做通 | `Normal` | 完整 Seedance 闲置 |
| 高 | `Working`、`Busy` | 另出视频；Busy 可用中心核旋转 / 脉冲 |
| 中 | `Help`、`Unavailable`、`Link`、`Pin`、`Person` | 能复用 Normal 视频的只加静帧附件 |
| 低 | 文本、准星、四种缩放、移动、候选 | 静帧即可 |

不要 17 个角色各烧一段 30 秒长视频。

---

## 9. 验收

- [ ] 静帧是用户确认过的 concept，不是量化稿
- [ ] 视频不是整身钟摆；有分层动作（主动作 / 跟随 / 点缀）
- [ ] 16 帧、128×128、硬 Alpha、棋盘已抠
- [ ] 整只角色在画布内，没有只剩半个帽子
- [ ] 热点 16 帧同一坐标，左上尖端没有明显乱跳
- [ ] 浅绿底 GIF 已给用户看过
- [ ] ANI 为合法 RIFF `ACON`、32 位、16 帧、`JifRate=6`
- [ ] 普通选择可被 `LoadCursorFromFileW` 加载；应用后关软件仍在动

---

## 10. 明确不做

- Prompt B 拆层、主题专用上千行 `build_assets.py` 派生续帧
- 高清逐帧重生再像素化
- 视频模型直接当成品、均匀截 8 张不处理
- 物理摇摆 / 挂坠充当本流程的动态
- 为「看起来在动」去加运镜、粒子风暴、换脸眨眼（若主题锁闭眼）
