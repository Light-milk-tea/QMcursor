# 通用 Windows 鼠标指针生图提示词

将本文件与一个包含 4–5 张参考图片的文件夹一起提交。不要要求用户另行指定颜色、主题或风格；先从参考图中提炼视觉系统，再生成一套完整指针。

---

## 可直接提交的任务指令

你是一名专业 UI 图标设计师。请读取随本提示词提交的参考图片文件夹，根据其中 4–5 张图片共同呈现的视觉语言，设计并生成一套原创 Windows 鼠标指针。

### 一、先分析参考图

在生成前，综合分析全部参考图，并在内部建立统一的视觉规范：

- 提取主色、辅色、强调色和轮廓色，不使用预设固定色板。
- 判断整体风格，如扁平、手绘、像素、复古、科技、可爱、极简、厚涂或其他风格。
- 提取轮廓粗细、圆角程度、几何语言、明暗方式、材质表现、细节密度和色彩比例。
- 找出反复出现且适合转译为指针的核心视觉元素，例如植物、动物、器物、纹样、符号或局部造型。
- 区分“风格特征”和“画面内容”：继承前者，重新设计后者。
- 多张参考图存在差异时，以重复出现的共同特征为主；以最清晰、最完整、最能代表整组风格的图片为辅助基准。
- 如果参考图足以判断风格，直接开始，不要追问用户颜色或风格。

先用 3–6 条简短文字总结你识别出的视觉规范，再开始生成。总结只用于说明，不要把文字画进图片。

### 二、设计原则

这是一套可实际使用的鼠标指针，不是场景插画，也不是把参考图缩小后直接贴在箭头旁边。

1. 不要拘泥于系统指针常见的三角形箭头形式，也不要只在默认箭头上换色或添加装饰。应优先根据参考图中的核心元素大胆重构外形，例如用动物、植物、器物、丝带、翅膀、宝石或抽象图形直接构成指针主体，让造型更有创意、主题辨识度和意外感。允许主体完全脱离传统三角箭头轮廓，只要仍保留对应功能的方向感、操作含义和明确热点，并确保缩小后能快速理解其用途。
2. 将参考图的视觉元素融入轮廓、填色、切角、附件或内部结构。
3. 同一套指针必须共享一致的色板、线宽、圆角、明暗、材质和视觉重量。
4. 优先保证 24×24 和 32×32 像素下的识别度；删去缩小后会糊成一团的细节。
5. 外轮廓清晰、结构紧凑、正交视图、无透视；功能性尖端必须准确。
6. 每枚指针主体居中并留足安全边距，任何部分不得贴边或被裁切。
7. 装饰只能服务于风格统一，不得遮挡热点、破坏方向或改变功能含义。
8. 除非参考图明确依赖渐变或材质才能成立，否则优先使用少量清晰色块。
9. 不模仿特定在世艺术家，不生成参考图中的签名、水印、品牌标识或可识别文字。
10. 文本选择、精确选择、手写以及所有调整类指针的主体线条和功能骨架不得过细；应在保持几何精度与热点准确的前提下使用清晰、饱满且与整套视觉重量协调的线宽，确保缩小后不断线、不显得单薄，避免影响观感。

### 三、生成顺序

不要一次生成包含 15 枚图标的总览拼图。最终交付必须是 15 张彼此独立的 1:1 图片。

先生成 `01-normal-select`。确认其风格提炼准确、热点清晰、缩小后可辨认后，将它与原始参考图共同作为后续 14 枚的风格参考。后续图片应像同一位设计师在同一套设计系统中完成。

依次生成：

1. `01-normal-select`（普通选择）  
   整体操作方向指向左上，最左上功能尖端为热点，必须锐利、清晰、无遮挡。不要强制采用系统三角箭头轮廓；可将参考图中的动物、植物、器物或抽象元素直接设计成具有明确指向性的主体。用户应能一眼判断指向和点击位置，但造型不必一眼看起来像标准箭头。

2. `02-help-select`（帮助选择）  
   与普通选择保持同一箭头主体，在右下方加入小型帮助标记；默认仅使用一个清晰问号。附件不得遮挡左上热点，不得出现其他文字。

3. `03-working-in-background`（后台运行）  
   与普通选择保持同一箭头主体，在右下方加入简洁的进行中标记，如 3 个点、短弧、叶片或与参考风格相符的节奏性元素。不得遮挡热点。

4. `04-busy`（忙碌）  
   严格围绕中心组织的环形或放射形结构，旋转中心位于画面正中心，适合后续制作循环旋转动画；轮廓均衡，不要附带鼠标箭头。

5. `05-precision-select`（精确选择）  
   严格对称的十字准星，上下左右四臂等长、夹角 90°，热点位于精确中心。风格化不能破坏准星精度；准星线条不得过细，应保持清晰、饱满，缩小后仍有足够的视觉重量。

6. `06-text-select`（文本选择）  
   清晰、垂直的 I 形光标，上下横杠平衡，热点位于中心。不得生成字母、单词或普通竖线；竖杆与上下横杠不得过细，缩小后不能断线或显得单薄。

7. `07-handwriting`（手写）  
   从右上指向左下的笔形指针，左下笔尖为热点，必须锐利、清晰、无遮挡。造型可采用与参考图一致的材质或装饰语言；笔身不得过细，在保留锐利笔尖的同时应有清晰、饱满的主体轮廓。

8. `08-unavailable`（不可用）  
   一眼可识别的禁止符号，通常为圆环加左上至右下斜杠；热点位于中心。几何关系清楚，避免装饰削弱符号含义。

9. `09-vertical-resize`（垂直调整）  
   严格垂直的上下双向箭头，上下对称，中心为热点，轴线不得倾斜；箭杆与箭头不得过细，应保持清晰、饱满的视觉重量。

10. `10-horizontal-resize`（水平调整）  
    严格水平的左右双向箭头，左右对称，中心为热点，轴线不得倾斜；箭杆与箭头不得过细，应保持清晰、饱满的视觉重量。

11. `11-diagonal-resize-nwse`（西北—东南调整）  
    沿左上至右下 45° 轴线的双向箭头，两端对称，中心为热点；不得生成相反方向。箭杆与箭头不得过细，应保持清晰、饱满的视觉重量。

12. `12-diagonal-resize-nesw`（东北—西南调整）  
    沿右上至左下 45° 轴线的双向箭头，两端对称，中心为热点；不得生成相反方向。箭杆与箭头不得过细，应保持清晰、饱满的视觉重量。

13. `13-move`（全方位调整）  
    上下左右四向箭头，四臂等长、夹角 90°，中心为热点，整体严格对称；四臂与箭头不得过细，缩小后不能断线或显得单薄。

14. `14-alternate-select`（候选选择）  
    垂直向上的箭头，顶部尖端为热点。与普通选择明显区分，但沿用整套视觉语言。

15. `15-link-select`（链接选择）  
    简洁的手型光标，食指垂直向上，指尖为热点；其余手指以最少形状概括。不得生成写实手、额外手指、手臂或人物。

### 四、每张图片都必须附加的强制要求

生成每一枚指针时，都同时执行以下要求：

> 单枚 Windows 鼠标指针图标，1:1 方形画布，主体居中，四周留足安全边距，正交视图，无透视，不裁切。严格继承本次参考图片分析得到的统一色板、轮廓、圆角、明暗、材质和细节密度，并与已经确认的 `01-normal-select` 保持同一套设计系统。图标必须适合实际 UI 光标使用，热点准确且无遮挡，缩小到 24×24 或 32×32 像素后仍能快速辨认。不要场景、装饰背景、标题、编号、标签、签名、水印、伪文字、人物或无关物体；不要直接复制参考图中的角色、Logo 或完整构图；不要出现模糊边缘、过密细节、错误方向、错误肢体、重复轮廓或被裁切部分。

> 生图阶段不要要求模型绘制“透明效果”，也不要在生图提示词中出现“棋盘格”“透明预览网格”等词，避免模型把透明预览画进像素。先选择一种未出现在指针色板中的高饱和纯色作为临时抠图背景，例如主体不含绿色时使用纯绿 `#00FF00`；背景必须完全平坦、单色、无渐变、无纹理、无阴影、无光晕。生成后必须进行实际图像处理：识别并删除临时背景，清除边缘溢色，将背景像素写为 Alpha=0，将图标本体保留为 RGBA，再保存最终 PNG。临时纯色图不是最终交付物。

### 五、一致性校验

每完成一张图，先与 `01-normal-select` 和已生成图片比较，再继续下一张。发现不一致时应重新生成或修正，不要带着偏差继续扩散。

逐项检查：

- 是否正确生成了目标指针类型，方向和几何结构是否准确。
- 热点是否位于规定位置，是否清晰、无遮挡。
- 色板、线宽、圆角、光影方向、材质和细节密度是否统一。
- 主体在画布中的占比和视觉重量是否与整套一致。
- 缩小到 32×32 和 24×24 后是否仍清晰，没有断线、糊边或细节粘连。
- 是否为真实 RGBA 透明背景，而不是画出来的棋盘格。
- 使用图像程序读取成品进行像素验证：文件模式必须包含 Alpha 通道；四角及全部背景区域的 Alpha 必须为 0。不能只根据图片查看器显示效果判断透明。
- 是否包含文字、水印、背景或参考图中的可识别受保护内容。

### 六、最终交付

- 输出 15 张独立 PNG，不输出拼图作为最终文件。
- 所有生成图片必须直接保存到本提示词和参考图片所在的当前文件夹；不要保存到其他目录，不要创建 `assets`、`output`、`generated` 等子文件夹。如果生图工具只能先输出到默认临时目录，生成完成后必须立即将图片移动到当前文件夹，并以当前文件夹中的文件作为最终交付。
- 最终交付前必须完成临时纯色背景抠图和 Alpha 像素验证。任何仍含纯色底、白底、灰底或画入像素的透明预览图案的文件都不合格，必须处理或重新生成。
- 推荐母版尺寸：1024×1024 或 2048×2048。
- 文件名严格使用上文的英文名称并加 `.png` 后缀。
- 全部图片使用相同画布尺寸、主体占比和安全边距。
- 另外提供一份简短的风格摘要，记录本次从参考图提取的色板、轮廓、材质和核心造型语言，便于后续补图。
- 最终转换为 `.cur` 或 `.ani` 前，应人工统一缩放、检查透明边缘，并设置准确热点坐标。
