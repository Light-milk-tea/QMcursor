## 〇、成品标准（最高优先级）— 高清像素风 concept

**已放弃「真 48×48 / 真 N×N 原生像素帧」路线。**  
以后成品一律以 **GenerateImage 产出的高清像素风 concept** 为准：既有清晰像素风，又要好看。

| 必须 | 禁止 |
|---|---|
| 用 GenerateImage + 角色参照 + 线框语言，做出 concept 级高清像素风 | **禁止**再压成真 48/32/64 原生像素格当正式成品 |
| 交付物即 `concept/<role>-concept.png`（可再导出多层 CUR） | **禁止手拼** PIL polygon/ellipse 拼角色 |
| 系统可用包：从 concept **透明抠底后 LANCZOS 缩到多尺寸 CUR**（32/48/64/96/128…） | **禁止** WASM / 最近邻量化成「真像素 00.png」交差 |
| 眼睛等细节按主题锁死（桃金娘：开眼、像素块面绿瞳，非眯眯眼、非过精致高清虹膜） | 禁止 concept 好看、另交一套丑真像素双轨 |

桃金娘试做结论：

- 好看：高清像素风 concept
- 失败：真 48 最近邻/量化稿明显掉档 → **不再做真像素正式帧**

导出 CUR 时允许高质量缩放；那是「把高清贴纸做成系统指针」，不是「翻译成原生像素画」。

## 一、风格锁死表

| 项 | 锁定值 |
|---|---|
| 成品形态 | **高清像素风 concept**（GenerateImage） |
| 系统封装 | concept 抠底 → 多层尺寸 CUR（LANCZOS）；热点按尖端比例换算 |
| 美观 | 对齐伊蕾娜 / 桃金娘 concept 标杆 |
| 描边 | 统一近黑硬描边，色块平涂 2–3 档 |
| 眼睛 | 按主题锁死；桃金娘默认 **开眼像素块面绿瞳**（禁止眯眯眼；禁止过精致虹膜） |
| 构图（角色态） | 左侧/左上热点器物 + 中央偏右 Q 版小人 |
| 功能态 | 简洁白+近黑经典形（高清像素风即可），不要塞角色 |

### 禁止

- 真 48 / 真 N 像素格正式帧、手拼脚本、WASM 量化正式帧
- 丢掉已确认 concept 另画一套
- 发色侵入脸区、糊成色团、双重毛边

### 与 Mon3tr / 旧 A2 / 真像素的对立

| 本路线（正确） | 已放弃 |
|---|---|
| 高清像素风 concept 即成品审美 | 真 48 原生像素 `00.png` |
| CUR 多层高质量缩放 | 最近邻压格当正式画 |
| GenerateImage 出图 | PIL 手拼小人 |

## 三、工作流

```text
W0 读样例
 → W1 GenerateImage 高清像素风 Normal concept（用户评美观）
 → W2 同法出其它角色态 concept
 → W3 功能态 concept
 → W4 可选：抠底导出多层 CUR
```

目录：

```text
<主题>/wireframe-concept/
  concept/<role>-concept.png
  package/          # CUR + theme.json
  preview/
```

每轮展示 **concept 原图**。不再要求真 48 ×8。

## 五、Prompt W1：Normal（concept = 成品）

```text
任务：为 [主题名] 生成普通选择高清像素风指针 concept（即成品图）。
保存：concept/01-normal-select-concept.png

【必须】Q 版；左上热点器物；近黑硬描边；平涂；干净可爱。
眼型按主题（桃金娘：开眼像素块面绿瞳）。
【禁止】手拼；真像素压格；WASM 量化当成品；照片风厚涂。
```

用户确认后即可 CUR 封装或扩角色；**不再做真像素 00.png**。
