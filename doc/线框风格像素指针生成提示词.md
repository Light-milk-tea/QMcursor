## 〇、成品标准（最高优先级）— 高清像素风 concept

**已放弃「真 48×48 / 真 N×N 原生像素帧」路线。**  
以后成品一律以 **GenerateImage 产出的高清像素风 concept** 为准：既有清晰像素风，又要好看。

| 必须 | 禁止 |
|---|---|
| 用 GenerateImage + 角色参照 + 线框语言，做出 concept 级高清像素风 | **禁止**再压成真 48/32/64 原生像素格当正式成品 |
| 交付物即 `concept/<role>-concept.png`（可再导出多层 CUR） | **禁止手拼** PIL polygon/ellipse 拼角色 |
| 系统可用包：从 concept **透明抠底后 LANCZOS 缩到多尺寸 CUR**（32/48/64/96/128…） | **禁止** WASM / 最近邻量化成「真像素 00.png」交差 |
| 眼睛等细节按主题锁死（桃金娘：开眼、像素块面绿瞳，非眯眯眼、非过精致高清虹膜） | 禁止 concept 好看、另交一套丑真像素双轨 |

桃金娘试做结论：

- 好看：高清像素风 concept
- 失败：真 48 最近邻/量化稿明显掉档 → **不再做真像素正式帧**

导出 CUR 时允许高质量缩放；那是「把高清贴纸做成系统指针」，不是「翻译成原生像素画」。

## 一、风格锁死表

| 项 | 锁定值 |
|---|---|
| 成品形态 | **高清像素风 concept**（GenerateImage） |
| 系统封装 | concept 抠底 → 多层尺寸 CUR（LANCZOS）；热点按尖端比例换算 |
| 美观 | 对齐伊蕾娜 / 桃金娘 concept 标杆 |
| 描边 | 统一近黑硬描边，色块平涂 2–3 档 |
| 眼睛 | 按主题锁死；桃金娘默认 **开眼像素块面绿瞳**；伊蕾娜默认 **闭眼横线** |
| 构图（角色态） | 左侧/左上热点器物 + 中央偏右 Q 版小人 |
| 功能态 | 白填 + 近黑描边 + 主题色点缀（伊蕾娜：紫轴 / 金星胸针），不要塞角色 |

### 禁止

- 真 48 / 真 N 像素格正式帧、手拼脚本、WASM 量化正式帧
- 丢掉已确认 concept 另画一套
- 发色侵入脸区、糊成色团、双重毛边

### 与 Mon3tr / 旧 A2 / 真像素的对立

| 本路线（正确） | 已放弃 |
|---|---|
| 高清像素风 concept 即成品审美 | 真 48 原生像素 `00.png` |
| CUR 多层高质量缩放 | 最近邻压格当正式画 |
| GenerateImage 出图 | PIL 手拼小人 |

## 三、工作流

```text
W0 读样例
 → W1 GenerateImage 高清像素风 Normal concept（用户评美观）
 → W2 其它角色态：能复用 Normal 姿势就复用，只加小装饰
 → W3 功能态：一张统一设计表裁切，禁止逐张分批生图
 → W4 抠底（仅边缘洪水）→ LANCZOS 多层 CUR → 应用试看
```

目录：

```text

  concept/<role>-concept.png
  package/          # CUR + theme.json
  preview/
```

每轮展示 **concept 原图**。不再要求真 48 ×8。

## 八、封装 CUR（可选）

```text
1. 抠底：只从画面边缘洪水填充品红 / 浅色底板
2. LANCZOS 多层尺寸写入 .cur（32/48/64/96/128/256）
3. 热点按尖端比例换算；写 theme.json（QMcursor 自制可标 category: 线框cursor）

```

### 抠底锁死（伊蕾娜踩坑）

银白发、白领、扫帚白尖都接近棋盘白/浅灰。

| 必须 | 禁止 |
|---|---|
| 浅色/棋盘底板：仅清除**与边缘连通**的浅色（`min(RGB)≥228` 且饱和度很低） | 全局把近白 / 浅灰像素当背景删掉 |
| 品红色键：圈内/环内封闭空洞也要清掉（禁止符、忙碌环中间） | 只做边缘洪水，导致 Busy / Unavailable 中间留品红 |
| 容差够吃底板、吃不进头发（不要用白底 + 容差 88 从边缘灌进发区） | 回退逻辑里 `r>180` 的灰白一律变透明 |
| 打包脚本不得用旧 assets 覆盖本轮已裁好的功能态 concept | 封装后再被旧图冲掉 |

应用图标同理：角色背后的实心白底板要边缘洪水清掉，但头发必须留下。

## 十一、伊蕾娜试做结论（2026-08）

成品主题：`QMcursor/src/qmcursor/themes/elaina_wireframe/`（「伊蕾娜·线框」）。  
工作目录：`伊蕾娜线框光标/`。Normal 标杆仍是 `concept/elaina-wireframe-normal-concept.png`。

### 角色锁死

- 闭眼横线、黑帽紫带金扣、黑袍金胸针、左侧竖握扫帚
- 扫帚柄顶端白尖 = 热点识别点，所有「还是这根扫帚」的角色态都要保留
- Help / Working / Unavailable 可加问号泡、沙漏、禁止符；**不要重画人体结构**

### Link 的正确做法

1. 复制已确认 Normal 原图（程序叠图，不要再 GenerateImage 重画小人）
2. 只加一颗主题金星；伊蕾娜挂在**扫帚白色尖端下面**（沿木柄下坠）
3. 失败案例：伸手指 + 斜握扫帚 → 白尖消失、形态跳变，用户明确否定

### 功能态的正确做法

1. 先出「调整×4 + 移动 + 精确」统一设计表，再裁切
2. 装饰语言与角色配色对齐：紫 `#6B5B9A`、金 `#E8C45A`、近黑描边
3. 第一版「光杆箭头」统一了但不耐看；第二版加内框 / 中心星框后才过关
4. Text / Pen / Alternate / Busy 可另开一张 2×2 表，星徽尺度仍要同一套

### 封装脚本注意

- 角色态从 assets 同步；功能态只从本轮统一表裁切
- `theme.json`：`is_custom=true`，`kind=cur`，`category=线框cursor`
- 改完必须 `apply_theme` 真机看切换，不能只看拼图预览
