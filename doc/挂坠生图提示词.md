# 指针挂坠（Charm）生图提示词

将本文件与目标主题的参考图、以及该主题的主指针图（通常为 `arrow.png`）一起提交，用于生成物理摇摆时悬挂在指针下方的末端饰物。

挂坠只提供**末端饰物**素材。连接指针与饰物的柔性绳索由 QMcursor 程序绘制；若把长链条画进图片，运行时会像僵硬摆钟。

成品安装文件名固定为主题目录下的 `pendant.png`（与 `arrow.png` 同级）。安装流程见项目 Skill：`.cursor/skills/add-cursor-pendant/SKILL.md`。

---

## 可直接提交的任务指令

你是一名专业 UI / 游戏图标设计师。请读取随本提示词提交的参考图片与主指针图，提炼统一视觉语言，设计并生成一枚可用于鼠标指针挂坠的末端饰物。

### 一、先分析参考图

在生成前，综合分析全部参考图与主指针图，并在内部建立统一的视觉规范：

- 提取主色、辅色、强调色、金属色、宝石色和轮廓色。
- 判断整体风格（扁平、赛璐璐、厚涂、像素、器物感等）。
- 提取轮廓粗细、圆角、明暗、材质与细节密度。
- 找出适合做成「吊饰 / 徽章 / 宝石」的主题符号（器物、纹样、标志性配饰等）。
- 选择参考图色板中没有的高饱和纯色作为临时背景，并记住精确十六进制色值。

先用 2–4 条简短文字总结视觉规范，再开始生成。总结只用于说明，不要把文字画进图片。

### 二、设计原则

1. **只要末端饰物**：圆形/盾形/花形徽章、宝石吊坠、主题器物碎片等；竖构图、主体居中、留足安全边距。
2. **顶部挂点清晰**：徽顶小环残段、吊环、或干净的外框顶点，便于程序识别北侧枢轴。
3. **禁止画上方长链条 / 绳索 / 棍状连杆**。程序会画柔性绳；烘焙长链会导致僵硬摆锤感。
4. 徽下最多允许 1–2 颗**短**坠饰（小珠、水滴宝石），不要做成整段硬直长摆。
5. 造型必须让人看出属于该主题：色板、线宽、器物语言与主指针一致。
6. 保证缩小后仍可识别（最终约缩到指针高度的 0.8–1.0 倍）。
7. 正交视图、无透视、无场景；外轮廓清晰。
8. 不要生成指针箭头、完整角色全身、大场景、文字、编号、水印、UI 边框。
9. 不要要求透明背景、棋盘格或透明预览；背景必须是指定纯色平面。
10. 不模仿特定在世艺术家，不生成可识别签名或品牌标识。

### 三、背景与输出

- 背景为纯色 `<BG_HEX>`：完全平坦、单色、无渐变、无纹理、无投影到背景上。
- 主体任何部位不得使用该背景色。
- 只生成这一枚挂坠，1:1 构图，推荐 1024×1024。
- 不要拼图、文字、编号或标签。

### 四、英文主 Prompt（可直接粘贴）

将 `<BG_HEX>` 替换为选定的临时背景色（例如 `#FF00FF`、`#00FF00`）。每次生成须附带主题参考图与主指针 PNG。

```text
A single hanging charm / medallion for a mouse-cursor pendant decoration,
matching the visual style of the provided cursor theme references.

Vertical composition, square 1:1 image, subject centered with safe margin.

Design (charm body ONLY):
- Top: a clear attach point on the top edge of the medallion
  (small gold bail, loop stub, or clean top of the frame — NOT a long chain).
- Main body: a compact ornament that reads the theme
  (emblem, gem, badge, flower, animal mark, artifact fragment, etc.).
- Optional: 1–2 tiny dangling gems/beads under the medallion only
  (short, decorative; do not make a long rigid chain).
- Style: clean anime / game-asset cel shading, crisp outlines, glossy gems,
  consistent with the reference cursor palette and line weight.

CRITICAL — do NOT include:
- A long vertical chain, rope, stick, or multi-link cord above the medallion
  (the app draws a flexible cord in code; a baked chain looks like a stiff pendulum).
- Cursor arrow / hat / full character / scene / text / watermark / labels.
- Transparent background, checkerboard, or transparency preview.

Background: flat solid color <BG_HEX>, completely flat, no gradient, no texture,
no shadow cast on the background. Subject must not use this color.

Only generate this one charm. No collage, no numbers, no UI chrome.
```

### 五、中文约束清单（生成后自检）

- [ ] 只有末端饰物，无上方长链 / 棍
- [ ] 顶部挂点明确
- [ ] 色与造型贴合主题主指针
- [ ] 背景为指定纯色，无透明底预览
- [ ] 无文字、水印、场景、指针箭头
- [ ] 竖构图，缩小后仍可辨认

### 六、安装说明（生成之后）

抠除临时背景并写入主题目录：

```powershell
python .cursor/skills/add-cursor-pendant/scripts/install_pendant.py `
  --input "<原图路径>" `
  --theme-dir "src/arkcursor/themes/<英文目录名>" `
  --background "<BG_HEX>"
```

校验：

```powershell
python .cursor/skills/add-cursor-pendant/scripts/install_pendant.py `
  --validate-only "src/arkcursor/themes/<英文目录名>"
```

启用 QMcursor「物理摇摆」并应用该主题后即可看到挂坠；无需修改 `theme.json`。
